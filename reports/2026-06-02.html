Microsoft Build 2026 개막: Project Polaris·Windows Agent Framework·Microsoft IQ 전격 발표
6월 2일 샌프란시스코 Fort Mason Center에서 Microsoft Build 2026이 개막했다. CEO 사티아 나델라는 약 2시간 30분의 기조연설에서 에이전트 AI를 Windows 개발 플랫폼의 핵심으로 내세우며 Project Polaris, Windows Agent Framework, Azure Agent Mesh, Azure HorizonDB, 그리고 'Microsoft IQ'라는 통합 AI 브랜딩을 대거 발표했다. 개발자가 로컬 PC에서 직접 실행 가능한 엣지 AI 모델 2종도 공개되어 클라우드 의존도를 낮출 수 있게 됐다.
